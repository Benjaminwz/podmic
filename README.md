# 錄音台 PodMic

專為 podcast 設計的錄音工具，針對 DJI Mic Mini 2 / Mic 2 調整過。分成手機 App 和電腦程式兩部分。

## 手機 App（Android）
- 48 kHz 錄音，存成 24-bit 或 32-bit 浮點 WAV，優先使用 USB 接收器；錄音中按音量鍵可以打標記
- 自動判斷 DJI 的聲道模式（單人、雙人各一軌、安全音軌）
- 提詞器（可以跟著講話的聲音捲動）、房間測量（頻譜、殘響時間）
- 跟電腦同步：電腦可以遙控錄音、改提詞稿，錄完自動把檔案傳到電腦

## 電腦程式（Windows）
- 看手機的音量條、遙控錄音、寫提詞稿、大螢幕提詞
- 接收器也可以直接插電腦錄
- **✂ 剪輯**：用波形選出講錯、不要的段落刪掉；播放時直接跳過刪掉的地方，聽到的就是剪完的樣子。
  可以先聽寫成文字，點一句就選取那一句。原始錄音不會被改。
- **一鍵後製**：照剪輯刪掉段落 → 修安全音軌的破音 → 兩個人音量拉齊 → 壓縮 → 剪掉太長的空白和單獨的贅字
  → 響度 −16 LUFS → MP3（含章節）、逐字稿、字幕、封面、上架資料
- 片頭片尾音樂、併入遠端來賓的檔案、批次處理、自動備份、筆電自動更新

## 怎麼用
1. 到 [Releases](../../releases) 下載 `PodMic-laptop.zip`（電腦）和 `PodMic.apk`（手機）。
2. 電腦：解壓縮後打開 `PodMic.exe`。手機：安裝 APK，跟電腦連同一個 Wi-Fi，打開後電腦會問要不要允許連線。
3. 照電腦上方的步驟提示：接麥克風 → 準備 → 錄音 → 收檔 → 後製 → 完成。

逐字稿、字幕、贅字剪除需要另外安裝[快字幕 QuickSub](https://github.com/Benjaminwz/quicksub)。

## 從原始碼執行／打包
- 電腦：`python pc/podmic.pyw`（需要 numpy、Pillow、sounddevice，以及 ffmpeg）；打包：`build_pc.ps1`
- 手機：`build_apk.ps1`（不用 Gradle，需要 Android SDK build-tools 與 JDK）；第一次會產生自己的簽章金鑰
