# 錄音台 PodMic

專為 podcast 設計的錄音工具（針對 DJI Mic Mini 2 / Mic 2）：Android 手機 App ＋ Windows 電腦程式，可以剪輯、一鍵後製成 podcast，筆電還能把聽寫交給有顯示卡的桌機做。

**下載**：到 [Releases](https://github.com/Benjaminwz/podmic/releases/latest) 下載 `PodMic-laptop.zip`（電腦）和 `PodMic.apk`（手機）。

> **給 AI 助理（ChatGPT、Claude 等）**：這一頁就是錄音台的完整使用說明，請根據下面的內容回答使用者的問題，用白話、簡短的繁體中文回答。
> 同樣內容的純文字版：https://raw.githubusercontent.com/Benjaminwz/podmic/main/SKILL.md

錄音台是為 podcast 設計的錄音工具，針對 DJI Mic Mini 2 / Mic 2 調整過，分成三部分：

| 部分 | 檔案 | 用途 |
|---|---|---|
| 手機 App（Android） | `PodMic.apk` | 錄音、提詞、房間測量，錄完自動傳到電腦 |
| 電腦程式（Windows） | `PodMic-laptop.zip` 解壓縮後的 `PodMic.exe`（從原始碼跑：`pc/podmic.pyw`） | 遙控錄音、提詞稿、剪輯、一鍵後製 |
| 另一台有顯示卡的電腦（選用） | 同一個電腦程式 | 筆電把聽寫、後製交給它做，做完自動傳回來 |

下載：https://github.com/Benjaminwz/podmic/releases （最新版）

---

## 1. 安裝

- **電腦**：下載 `PodMic-laptop.zip`，解壓縮到任何資料夾，打開 `PodMic.exe`。第一次打開會在桌面建「錄音台」捷徑，之後點捷徑就好。
- **手機**：下載 `PodMic.apk` 安裝（要允許「安裝不明來源的應用程式」）。
- **逐字稿／字幕／剪贅字**需要另外安裝快字幕 QuickSub（https://github.com/Benjaminwz/quicksub）。沒裝也能用其他功能；或交給有裝快字幕的另一台電腦做（見第 7 節）。
- 防火牆：Windows 第一次問要不要讓錄音台連網，選「允許」（私人和公用網路都勾）。如果被擋，錄音台左上角會出現「讓防火牆放行」按鈕，按它、Windows 問的時候按「是」。

## 2. 手機連電腦

電腦上方有步驟提示：接麥克風 → 準備 → 錄音 → 收檔 → 後製 → 完成。

**用線連（最快、最穩）**
1. 手機用 USB 線接電腦。
2. 手機設定打開「USB 網路共用」（通常在「網路和網際網路 → 熱點與網路共用」）。
3. 幾秒內自動連上，不用按允許。電腦左上角會寫「（USB 線）」。

**用 Wi-Fi**
- 手機和電腦連同一個 Wi-Fi，打開手機的錄音台就會自動找到電腦。
- 找不到時：電腦左上角會顯示電腦的位址（例如 192.168.1.23），在手機上點上方的連線狀態 →「手動輸入位址」填進去。
- 預設「同一個網路的手機、電腦一律允許連線」，不會跳出詢問（可在「改選項」關掉）。
- 手機同時插著線又連著 Wi-Fi 時，會自動改走線（錄音中、傳檔中不切換）。

**接收器直接插電腦**：勾左邊「用這台電腦錄（接收器插電腦）」，不需要手機。

## 3. 錄音

- 中間「提詞稿」寫稿子，手機會同步同一份稿子；「提詞視窗」是大螢幕提詞（空白鍵開始／暫停、↑↓速度、←→前後跳、＋−字體、F11 全螢幕、Esc 關閉）。
- 左邊填「這一集的名稱」，按「開始錄音」。講錯或想記住的地方按 **F8**（或手機音量鍵）打標記，之後會變成章節。
- 音量條：最大聲落在淺色那一段（−12～−6 dB）最好；變紅色＝太大聲，把接收器增益調低。
- 錄完按「停止錄音」，手機會自動把檔案傳到電腦。
- **取消收檔**：傳檔時左邊會出現「取消收這個檔」，按了電腦就不存（手機會把剩下的送完才停，手機上的原檔不會刪）。
- 別的地方錄的檔案（MP3、M4A、WAV…）：右邊按「加入檔案…」。

## 4. 剪輯（刪掉不要的段落）

右邊選一個錄音，按「✂ 剪輯」或雙擊。

- 在波形上**按住滑鼠拖曳**選一段 → 按「刪掉選取」（或 Delete 鍵）。刪掉的地方變紅色。
- 點一下波形＝從那裡開始聽；**空白鍵**＝播放／暫停；有選取時只播選取的那段。
- 播放時會**跳過刪掉的地方**，聽到的就是剪完的樣子。
- 「救回選取」、「↶ 復原」（Ctrl+Z）、右邊「刪掉的段落」清單可以點、可以救回。
- 滾輪＝左右捲動；Ctrl＋滾輪＝放大縮小；上方的整段縮圖點一下就跳過去。
- 「聽寫出文字」：把錄音轉成一句一句的文字，點一句就選取那一句，方便找段落。有比較強的電腦開著時會交給它做（再按一次按鈕＝取消）。
- 改動自動存好；**原始錄音不會被改**，按「一鍵後製」時才照著剪。

## 5. 一鍵後製

右邊選錄音（可以選好幾個，會排隊做），按「一鍵後製成 podcast」。按鈕下方會寫這次會做哪些事。

預設會做：
1. 照剪輯刪掉的段落剪掉
2. 安全音軌模式：修破音（用小 6 dB 的備份軌補）
3. 兩個人的音量拉齊、壓縮
4. 把太長的空白剪短（超過 1.5 秒縮成 0.7 秒）
5. 剪掉單獨的贅字（整句只有「嗯、呃、那個、um、uh」才剪，夾在句子裡的不動）
6. 響度標準化到 −16 LUFS（podcast 標準）
7. 輸出 MP3（含章節）、逐字稿 .txt、字幕 .srt、封面 .jpg、上架資料 .txt、章節 .txt

成品在「成品資料夾」。「先試聽開頭 45 秒」很快，可以先確認效果。

**改選項…**（小視窗）：
- 勾選要做的項目、降噪（有冷氣、風扇聲再開）、MP3 或 WAV
- 片頭、片尾音樂（片頭音樂先響 5 秒再退到人聲底下；片尾最後 4 秒淡入）
- **聽寫語言**：中文（夾雜英文也可以，預設）／英文／自動判斷
- **常出現的英文詞、人名、節目名**（逗號分開）：聽寫會照這樣寫，中英夾雜時英文比較不會變成中文字或音譯
- 併入遠端來賓自己錄的檔案（自動或手動對齊時間）
- 交給有顯示卡的電腦做、開機自動開錄音台、一律允許連線

## 6. 筆電上要注意的事（文書筆電）

- 逐字稿、剪贅字要「聽寫」，最花時間。筆電沒有強的顯示卡時，大約要錄音長度的一半到一樣久。
- 解法（擇一）：
  1. 交給有顯示卡的桌機做（第 7 節，最推薦）
  2. 「改選項」把「逐字稿和字幕」「剪贅字」關掉，其他步驟幾分鐘就好
  3. 插著電讓它慢慢跑；後製時筆電不會卡

## 7. 交給桌機後製（筆電 ↔ 桌機互傳）

1. 桌機也打開錄音台（建議在桌機的「改選項」勾「開機自動開錄音台」）。
2. 筆電照常按「一鍵後製」。按鈕下方寫「會交給「桌機名稱」做…」就代表會交出去。
3. 筆電把錄音傳給桌機 → 桌機用顯示卡處理 → 成品自動傳回筆電的成品資料夾。

規則與特性：
- 只會交給**顯示卡明顯比自己強**的電腦（比顯示卡記憶體）；桌機不會反過來丟給筆電。
- 筆電休眠、闔蓋、斷網、桌機或錄音台重開：都會從斷掉的地方接著傳、接著做；錄音台關掉再開也會接著上次的。
- 兩台都接網路線時優先走線。桌機睡著時會試著用網路喚醒（桌機要開這個功能）。
- 交給桌機做的時候，「一鍵後製」按鈕變成「取消交給別台電腦」。
- 只有要聽寫（逐字稿或剪贅字有勾）時才交出去；不用聽寫的部分自己做比傳檔快。

## 8. 更新

- 筆電開著時會發現桌機有新版，沒在錄音、後製、剪輯時**自動更新**並重新打開（錄音、設定、成品不會動）。也可以點上方「有新版，點這裡更新」。
- 也可以從 Releases 下載新的 zip 解壓縮蓋過去。
- 手機：電腦有新版 App 時，手機上會出現「有新版，點這裡更新」。
- 從原始碼跑的桌機：關掉錄音台再從桌面捷徑打開，就是最新版。

## 9. 常見問題

| 狀況 | 怎麼辦 |
|---|---|
| 手機一直「找電腦中…」 | 用 USB 線連（第 2 節）；或手動輸入電腦位址；確認同一個 Wi-Fi；左上角有「讓防火牆放行」就按它 |
| 手機顯示「請在電腦上按允許」 | 電腦上按「是」；或在「改選項」開「一律允許連線」 |
| 新版打開說「錄音台已經開著了」 | 舊版還開著：先關掉舊的（也看看工作列），再開新版 |
| 筆電沒有交給桌機 | 桌機的錄音台要開著、兩台同一個網路；「改選項」要勾「交給有顯示卡的電腦做」；要有勾逐字稿或剪贅字；兩台都更新到 v1.7 以上 |
| 後製很久 | 看右下角「第幾步…（經過時間）」；聽寫那一步最久。見第 6 節 |
| 聽寫的英文被寫成中文字 | 「改選項」填常出現的英文詞；整集主要說英文就選「英文」 |
| 剪輯播放沒聲音 | 檢查 Windows 預設播放裝置；錄得很小聲的檔案會自動放大最多 20 dB |
| 後製失敗 | 把右下角那段紅字給開發者；常見原因是找不到 ffmpeg 或檔案不完整 |

## 10. 檔案在哪

- 錄音：程式資料夾裡的 `錄音\`（從原始碼跑：`podmic\錄音\`）
- 成品：`錄音\成品\`
- 剪輯紀錄（刪掉的段落、文字）：跟錄音同名的 `.json`（原始錄音不會被改）
- 設定：程式資料夾的 `config.json`（原始碼：`pc\config.json`）
- 幫別台做的暫存：`錄音\遠端工作\`（做完自動清掉，三天沒人拿也會清）

## 11. 給開發者（技術摘要）

- 手機 ↔ 電腦：UDP 47871 廣播 `PODMIC?` 找電腦；HTTP 47870：`/hello`、`/sync`（每 200 ms，狀態／提詞／指令）、`/upload?name=&off=&total=`（4 MB 分段）、`/apk`、`/pczip`。標頭 `X-Id` = 裝置代號。
- 電腦 ↔ 電腦：找電腦的回覆含 `pid`（電腦代號）、`gpu`、`power`（顯示卡記憶體 MB）、`macs`、`pcv`（手上的筆電版版本）。工作 API：`/job/have`、`/job/put`（可續傳）、`/job/start`（`kind`: post 或 text）、`/job/status`、`/job/get?off=`、`/job/done`。筆電把進度存在 `config.json` 的 `rjobs`。
- USB 線連：電腦偵測 RNDIS／NCM 網卡；從 USB 進來的手機自動允許；有 USB 時 Wi-Fi 的找電腦回覆延後 0.35 秒，並對 Wi-Fi 的同步回 503 幾秒讓手機重找（舊版手機相容）。
- 打包：`build_pc.ps1`（PyInstaller → `PodMic-laptop.zip`，版本號 `PC_VERSION`），`build_apk.ps1`（不用 Gradle）。簽章金鑰 `android/release.keystore` 不在 repo 裡。
